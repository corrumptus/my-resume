Projeto pessoal

COUP - jogo de cartas

COUP é um jogo de turnos onde o último jogador com cartas vence e cada carta possui uma habilidade especial única.

Descrição

  • Desenvolvimento da interface da partida e das interações realizadas pelos jogadores.
  • Implementação da lógica de gerenciamento e persistencia do estado das partidas no servidor.
  • Modelagem do banco de dados de usuários e partidas.
  • Desenvolvimento de testes automatizados para validação dos estados e transições de turno.
Next.js TypeScript Node.js SQLite Jest
